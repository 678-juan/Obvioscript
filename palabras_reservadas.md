# Palabras reservadas de ObvioScript

ObvioScript utiliza expresiones cotidianas y sarcásticas colombianas como palabras reservadas del lenguaje.

Cada expresión tiene una función específica y debe conservar siempre el mismo significado dentro de la sintaxis.

| Palabra reservada | Equivalente | Función |
|---|---|---|
| OBVIO_BOBIS | if / SI | Inicia una condición |
| Y_ENTONCES | then / ENTONCES | Introduce la acción que se ejecutará |
| ENCIMA | and / Y | Une dos condiciones que deben cumplirse |
| O_QUE | or / O | Une condiciones alternativas |
| YA_DIJO | true | Representa un valor verdadero |
| NI_POR_EL_PUTAS | false | Representa un valor falso |
| SI_QUE_DIJO_NAVIDAD | ERROR | Representa la aparición de un error |

## Tipos de variables

ObvioScript también utiliza nombres propios para representar los tipos de datos.

| ObvioScript | Tipo equivalente | Descripción |
|---|---|---|
| CUENTE_PUES | int | Números enteros |
| CON_DECIMALES_Y_TODO | double | Números decimales |
| SI_O_NO_PUES | boolean | Valores verdadero o falso |
| ECHE_EL_CUENTO | String | Cadenas de texto |

## Ejemplos

```text
CUENTE_PUES edad = 17

CON_DECIMALES_Y_TODO valor_sesion = 45000.0

SI_O_NO_PUES estacion_disponible = YA_DIJO

ECHE_EL_CUENTO experiencia = "terror"
